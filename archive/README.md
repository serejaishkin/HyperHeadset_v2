# archive

Files that are not part of the application itself, kept for reference (moved here during repo cleanup):

- `reverse-engineering/` - extracted HP NGENUITY 2 package and archives used while reverse-engineering the protocol.
  These are third-party proprietary binaries; they are kept only locally for research and should not be redistributed.
- `old-docs/` - notes and prompts from earlier work and from the upstream HyperHeadset fork.
- `build-leftovers/` - old build outputs, AppImages, logs, scratch files.

Nothing in this folder is used by the build.
